# Teams — 2026

Rosters for the 2026 season, grouped by team. For players who moved teams
between 2025 and 2026, this page shows only their 2026 contract — see the
[2025 page](/teams/2025) for their earlier team.

**Role Scarcity methodology**: three categories — WK-Batsmen, All-rounders,
and Pace-leaning All-rounders (a subset of All-rounders) — each scored by
how rare that category is in the full player pool, min-max normalized so
the rarest category scores 10, the most common scores 1, and categories in
between are placed proportionally based on their actual player count. The
table below shows a single **Role Scarcity** column: the *maximum* score
across whichever categories a player actually qualifies for, or **NA** if
none apply.

Price is shown only when the contract type is `auction` or `retained` —
`replacement` signings (in-season injury/other replacements) don't have a
comparable public price, so it's intentionally blank for them.

```sql roster_data
select * from neon.team_roster
```

```sql season_roster
select * from ${roster_data}
where active_2026
```

```sql filtered_roster
select
    team,
    player_name,
    playing_role,
    nullif(concat_ws(', ',
        case when is_overseas then 'Overseas' end,
        case when is_captain then 'Captain' end,
        case when is_wicketkeeper then 'Keeper' end
    ), '') as flags,
    nullif(concat_ws(' · ',
        upper(substr(contract_type_2026, 1, 1)) || substr(contract_type_2026, 2),
        case when price_2026 is not null then '₹' || price_2026 || ' Cr' end
    ), '') as contract,
    coalesce(role_scarcity::text, 'NA') as role_scarcity
from ${season_roster}
order by team, player_name
```

```sql teams_list
select distinct team from ${filtered_roster} order by team
```
