# Teams - 2026

```sql roster_data
select * from neon.team_roster
```

```sql season_roster
select * from ${roster_data}
where active_2026
```

```sql filtered_roster
select
    team,
    player_name,
    playing_role,
    case when is_overseas then 'Yes' end as overseas,
    nullif(concat_ws(', ',
        case when is_captain then 'Captain' end,
        case when is_wicketkeeper then 'Keeper' end
    ), '') as additional_flags,
    nullif(concat_ws(' · ',
        upper(substr(contract_type_2026, 1, 1)) || substr(contract_type_2026, 2),
        case when price_2026 is not null then '₹' || price_2026 || ' Cr' end
    ), '') as contract,
    coalesce(role_scarcity::text, 'NA') as role_scarcity
from ${season_roster}
order by team, player_name
```

```sql teams_list
select distinct team from ${filtered_roster} order by team
```

## Scarcity vs Output

```sql mvp_data
select * from neon.mvp_filterable
```

```sql mvp_2026
select player_id, round(sum(batting_mvp) + sum(bowling_mvp), 2) as total_mvp
from ${mvp_data}
where season = 2026
group by player_id
```


```sql scarcity_output
select
    tr.player_name,
    tr.team,
    tr.role_scarcity,
    coalesce(mvp.total_mvp, 0) as total_mvp,
    case
        when tr.price_2026 is null then 'No price data'
        when tr.price_2026 < 2 then 'Under 2 Cr'
        when tr.price_2026 < 5 then '2 to 5 Cr'
        when tr.price_2026 < 10 then '5 to 10 Cr'
        else '10 Cr and above'
    end as price_tier
from ${roster_data} tr
left join ${mvp_2026} mvp on mvp.player_id = tr.player_id
where tr.active_2026 and tr.role_scarcity is not null
  and tr.team in ${inputs.scatter_team_filter.value}
```

Only players with a Role Scarcity score are plotted (WK-Batsmen,
All-rounders, Pace-leaning All-rounders); everyone else has no scarcity
axis to place them on. Color is the 2026 contract price tier, not a third
axis, consistent with the no-blended-score approach used everywhere else
on this site. Read it as a quadrant:

- **High scarcity, high output**: the clearest retain/target case.
- **High scarcity, low output**: the genuinely hard call, a scarce role
  that hasn't (yet) produced; worth a note, not an automatic decision.
- **Low scarcity, high output**: a good player in a replaceable role;
  lower priority than the first group under budget pressure.
- **Low scarcity, low output**: a clear release/pass candidate.

## About this page

Rosters for the 2026 season, grouped by team. For players who moved teams
between 2025 and 2026, the roster list above shows only their 2026
contract; see the [2025 page](/teams/2025) for their earlier team.

**Role Scarcity methodology**: three categories (WK-Batsmen, All-rounders,
and Pace-leaning All-rounders, a subset of All-rounders), each scored by
how rare that category is in the full player pool, min-max normalized so
the rarest category scores 10, the most common scores 1, and categories in
between are placed proportionally based on their actual player count. The
roster tables above show a single **Role Scarcity** column: the *maximum*
score across whichever categories a player actually qualifies for, or
**NA** if none apply.

Price is shown only when the contract type is `auction` or `retained`;
`replacement` signings (in-season injury/other replacements) don't have a
comparable public price, so it's intentionally blank for them. Some
contracts currently labeled `retained` are very likely trades (see the
project handover notes); those labels are pending a data correction.
